ライブラリの準備が必要になった場合:

1. エクスプローラーでこのプロジェクトフォルダを開きます。
2. `prepare-dependencies.cmd` をダブルクリックします。
3. `SUCCESS: Dependencies are ready` が出たら完了です。何かキーを押すと閉じます。
4. `ERROR` が出た場合は表示されたエラーをCodexに伝えてください。

PowerShellで実行する場合:

```powershell
Set-Location -LiteralPath 'G:\マイドライブ\02_AI・開発・プロンプト\Dragon-game-park'
pwsh -NoProfile -File .\scripts\prepare-dependencies.ps1
npm.cmd run dev
```

参考用コピーの依存関係を再準備する場合は、メインフォルダから次を実行します。

```powershell
pwsh -NoProfile -File .\scripts\prepare-dependencies.ps1 -ProjectRoot .\bakuretsu-reference
```

Google ドライブのファイルをオフラインでも使う場合:

1. `Windows` キーを押しながら `E` キーを押してエクスプローラーを開きます。
2. 上のアドレス欄に `G:\マイドライブ\02_AI・開発・プロンプト` を貼り付け、Enterを押します。
3. `Dragon-game-park` を右クリックし、`オフライン アクセス` → `オフラインで使用可` を選びます。
4. フォルダに緑のチェックが表示されるまで待ちます。表示がない場合は右クリックの `その他のオプションを確認` も確認してください。

オフラインにするとローカルの保存容量も使います。手順は [Google公式ヘルプ](https://support.google.com/drive/answer/2375012?hl=JA) に基づいています。
