- UNOの案内ワイプと「カード効果」ボタンが重ならず、横方向の文書あふれ・Viteエラー画面・壊れた画像がない。
- ババ抜き出目3だけに700msの場面画像。699msで存在し、700msで消える。結果パネルは残る。

## cold / warm画像条件

Coldは各サイズで新しい独立browser context。場面画像未マウントの状態で公開dice-stageのpreloadを開始。
Lv3シャッフル画像のResource Timing:375px=5.0ms、390px=9.6ms、900px=4.7ms、転送200638 bytes（本体200338 bytes）、initiator=`link`。
Warmは同じ宣言者の場面画像＋fallback URLのpreload完了後にカットインをマウント。fixtureは読込完了を待って条件を作る。実ゲームの既存サイコロ表示窓1700msには待機を追加していない。
これらはlocalhost・通信速度制限なしの測定。本番ネットワークや低速回線での計測ではない。
UNOの短い実導線では場面がまだ発生しないため、Chromeの「preloadを数秒以内に使用していない」警告が3URL×3画面=9件出る。先の場面に備える意図した取得。error/pageerrorは0件。
