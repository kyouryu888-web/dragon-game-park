# ドラゴン演出 v2 — 比較プレビュー

2026-10-04 の画像候補を、既存のゲーム画面の中で比較するためのデザインデモです。
本番ゲームの変更、PR、公開は含みません。

## 開き方

既存の Vite 開発サーバーで次の URL を開きます。

`http://127.0.0.1:5177/docs/design/dragons/presentation-v2/2026-10-04/preview.html`

開発サーバーが無ければ、リポジトリのルートで `npm run dev -- --host 127.0.0.1 --port 5177 --strictPort` を実行します。
依存関係の再準備が必要な場合は `pwsh -NoProfile -File ./scripts/prepare-dependencies.ps1` を使います。

## 比較できること

- UNO: ドロー2で返し、合計4枚になる場面。旧ドロー返し画像、公開済みの Lv3 画像、今回の Lv3 候補を比較します。
- ババ抜き: 現行のサイコロ判定パネルと、今回のシャッフル画像候補。
- 390 × 844 px と 900 × 700 px の実寸画面。
- ワイプ、全画面の見せ場、余韻を静止比較。「演出を再生」で順番に確認。
- 「動きを抑えて見る」と OS の reduced motion 設定に対応。

URL の `game=uno|babanuki`、`version=old|current|proposed`、
`viewport=mobile|desktop`、`phase=wipe|cutin|after`、`reduced=0|1` で条件を保存できます。
`embed=1` は比較画面内部の iframe 用です。

## 表示の根拠と限界

- UNO は実際の `UnoTableView` と `UnoCinematicOverlay` をテストデータで描画します。
- ババ抜きは実際の `BabanukiTable` と `DiceResultPanel` をテストデータで描画します。
- ワイプの白い円・緑の輪郭・既存の表情画像は既存コンポーネントのままです。
- 比較用 iframe 内の React adapter で描画後に画像を差し替え、選択した画像の読込完了を確認します。ゲーム本体のファイルは変更しません。
- 旧 UNO は別の段位のドラゴンです。カードの構図の参考で、Lv3 の同一性比較ではありません。
- ババ抜きの既存シャッフルには全画面ドラゴン画像が無いため、旧画像は選択できません。
- 候補の台詞と軽い表情切替はデザイン案です。人間のみの対局、イベント検出、キュー、オンライン同期は未配線です。
- UNO の再生は比較用の前ワイプ1400ms → 既存カットイン2400ms → 比較用の余韻1400msです。
- ババ抜きは既存の判定1700ms → 出目3の移動2500ms → 結果保持500ms（計4700ms）を再現します。候補画像のズームは行いません。出目4への適用はしません。
- 再生は比較用で、実際のカード再配置や既存ゲームの ACK・ゲーム進行時間は変更しません。
- 出目3の候補は伏せ札だけを描き、交換先・ジョーカー位置・非公開の手札を表示しません。
- 横幅が900px未満のウィンドウでPCを選ぶと、比較用枠を横スクロールできます。画面サイズを縮小して隠すことはありません。
- 画像候補を原寸で開くリンクと、前回検証した実画面キャプチャのリンクを併記しています。

- ババ抜きの候補カットイン中だけ既存結果パネルを隠し、候補内に公開の出目3を表示します。判定・余韻の段階で既存パネルへ戻ります。
