# publish-game

このスキルは手順の実体を持ちません。リポジトリルートの **`PUBLISHING.md`** が
唯一の正となる手順書です。次を行ってください:

1. `PUBLISHING.md` を読む。
2. そこに書かれた手順（ローカル検証ゲート → PR作成 → マージ前のCI/Vercelステータス確認
   → マージ → マージ後の本番デプロイ確認 → ユーザーへの報告）を、番号順にそのまま実行する。
3. `PUBLISHING.md` の「オンライン対戦ゲームを追加する場合の特別ルール」に該当する変更が
   含まれる場合は、そちらの手順（Supabaseへの手動SQL実行をユーザーに依頼する）も守る。
4. `PUBLISHING.md` の「必ず立ち止まって人に確認するべき条件」に当てはまったら、
   絶対に自己判断で進めず、ユーザーに確認する。

手順の内容をこのファイルに複製しないこと。将来 `PUBLISHING.md` が更新されたら、
このスキルは自動的に最新の手順に従うことになる。
