# ドラゴンゲームパーク

スマホ中心で遊べる Web ゲーム集です。  
最初のゲームとして、木製ボード風のカラハ式マンカラを実装しています。

## 技術構成

- React 19
- TypeScript
- Vite 8

## 主な機能

- ゲーム選択画面
- マンカラ設定画面
- マンカラ対局画面
- 人間 vs 人間
- 人間 vs CPU
- カラハ式マンカラルール（追加ターン・捕獲）
- 石が宙を飛ぶアニメーション
- スマホ・タブレット・PC 対応 UI

## 開発コマンド

Google ドライブ上で開発する場合、依存パッケージの準備はフォルダ内の
`prepare-dependencies.cmd` をダブルクリックしてください。`SUCCESS` が表示されたら完了です。
`npm install` / `npm ci` を G ドライブ上で直接実行すると書き込みエラーになる環境のため、
補助スクリプトが一時的にローカルディスクで準備し、検証してからコピーします。
既に準備済みの場合、通常の起動時に繰り返す必要はありません。

```bash
# 通常のローカルディスクで依存パッケージをインストールする場合
npm install

# 開発サーバーの起動（ブラウザで http://localhost:5173 を開く）
npm run dev

# 自動テストの実行
npm run test

# 本番用ビルド
npm run build
```
